SEAM is installed
=================

Thanks for trying SEAM. Three things worth knowing right now.

1. Start it from the Start Menu
   "SEAM" opens a console window and starts looking for your phone.
   "SEAM diagnostics" (Start Menu) prints what was found without connecting.

2. Your phone must authorise this PC
   Enable Settings -> Developer options -> USB debugging, plug the phone in, and
   accept the "Allow USB debugging?" prompt on the phone. Until you do, SEAM
   reports the device as "unauthorized" - that is the expected state, not a bug.

3. adb and the Android agent are already installed
   SEAM ships Android Platform-Tools in C:\Program Files\SEAM\platform-tools and
   seam-agent.jar next to seam-host.exe. There is nothing to add to PATH, nothing
   to copy into %TEMP%, and no .NET installation required.

If something does not work:

  seam-host.exe --diagnose

prints the install folder, the adb it resolved, the agent jar it resolved, the
pairing-key fingerprint (never the key), and the devices adb can see. Attach that
output to an issue at https://github.com/CalebPiusC/Seam/issues.

Your pairing key lives at %USERPROFILE%\.seam\auth_key and survives upgrades.
Uninstalling SEAM asks before deleting it, and keeps it if you say no.

Full notes: README-WINDOWS.txt in the SEAM install folder.
